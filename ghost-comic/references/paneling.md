# 分鏡：一頁怎麼切、哪格要大

借的是 HxH 那種日式少年漫畫的分鏡原則，不是畫風；prompt 裡永遠不寫作者或作品名。

## 一頁

- 一頁 3 到 6 格，大小要有落差。整頁一樣大的格子讀起來像幻燈片；條漫一列一張大圖也是。
- **格子大小照重要性給**：主要角色第一次登場、揭露、全篇最僵的那一刻（例：主角半蹲在沙發前不敢坐下）給大格，佔半頁左右。手按開關、眼睛特寫這種過場給小格。
- 每頁最多一個大格；揭露那頁可以一個大格加一個插格。
- 列的變化：
  - 一列三格：快節奏的連續動作，例如喀一聲開燈、走廊亮了、對方說「不是。」
  - 直欄堆疊：一邊一格高、另一邊疊兩格，或兩邊都疊但切法不同，格線就錯開，不會整頁都是方格。
  - 插格：小格疊在大格上，放細節特寫，例如嘴唇。
- 頁的最後一格是翻頁前讀者停住的地方：放一個問題、一個長格的空走廊，或一句沒說完的話。

## 第一頁

- 一條外景放標題，交代在哪裡。
- **前情提要寫進主角登場的大格裡**：我是誰、住在哪、為什麼一個人、現在在做什麼，分兩個旁白框，右上先讀、左下後讀。
- 每個主要角色第一次出現時放名牌（`tag`），再加一句介紹（「大學同學。大家都知道她『看得到』」）。
- 第一頁不要放驚嚇，放第一個小異常的徵兆就好（眼神飄到主角後面）。

## 對話

- 正反打：兩個人的來回用兩個中格並排，一人一格。
- 反應用小格，常常只畫眼睛。
- 從裝置傳來的聲音用 `screen` 或 `phone` 框，在場的人說的話用 `speech`，讀者靠框的形狀就知道是誰在說，不必每個框都拉尾巴。

## 恐怖的節奏

- **同構圖重複**：同一個鏡位畫三次，什麼都沒有；第四次一樣的構圖裡多了東西。三次空的那幾格，構圖要一模一樣，靠參考圖鎖住（`panel:` 參考加「Keep the same camera angle ... Add only this」）。
- **透過第三者看見**（ghost-story 的 proxy_sighting 機制）：鬼只出現在對方的螢幕裡（`screen` 加 `pip`），主角自己看的那幾格永遠是空的。
- **揭露放在翻頁後的第一眼**：新的一頁最上面一格，或整頁大格；前一頁用一個安靜的長格收。
- 無字格控制時間：黑掉的螢幕、狗坐起來盯著走廊。
- 回憶：無框、邊緣暈白、色調比現在亮。
- 最後一格：回到現在、比一般格大，停在一個細節上（電視開著、他不看）。

## 鬼要露多少

照 ghost-story 骨架的 `ghost_explicitness` 上限：

| 上限 | 漫畫裡 |
|---|---|
| 0 | 不畫鬼。只畫被動過的東西和人的反應 |
| 1 | 只畫跡象：門縫、影子、旁人的臉 |
| 2 | 一格局部：畫面邊緣、很小、被東西擋住 |
| 3 | 可以一格看見，但**預設仍然克制**：比活人小、臉大半在陰影裡、只露輪廓和一兩個特徵（白短髮、大耳朵、碎花睡衣） |

上限 3 也不要把鬼畫成畫面裡最大、最清楚的東西。擁有者看過一次大而清楚的阿嬤後要求「人物太大，面部可以看不清楚」。要清楚露臉的版本，得是使用者明說。

## 光線和場景

- 同一段劇情只用一種光線狀態，例如只開落地燈、牆和天花板塗黑。狀態改變要有原因，而且畫出來（按開關「喀」之後走廊才亮）。
- 每個光線狀態先畫一格廣角、挑定，之後同場景的格子拿它當場景參考，不要拿白天的場景卡。
- 同一個鏡位的格子，人物在畫面裡的大小要一樣。
